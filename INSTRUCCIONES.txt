2. CÓMO SUBIRLA A GITHUB Y ACTIVAR GITHUB PAGES (PASO A PASO)
-------------------------------------------------------------------

MÉTODO 1: DESDE LA WEB DE GITHUB (Sin comandos, muy fácil):
1. Inicia sesión en https://github.com
2. Haz clic en "New repository" (Nuevo repositorio).
3. Nombre del repositorio: ej. "xv-stefani" o "mis-15-stefani".
4. Selecciona "Public" (Público) y haz clic en "Create repository".
5. En la pantalla que aparece, haz clic en "uploading an existing file" (subir archivos existentes).
6. Arrastra los archivos y carpetas:
   - index.html
   - carpeta "assets"
   - carpeta "css"
   - carpeta "js"
7. Haz clic en "Commit changes".
8. Ve a la pestaña "Settings" (Configuración) de tu repositorio.
9. En el menú de la izquierda, entra en "Pages".
10. En "Branch", selecciona "main" (o "master") y carpeta "/ (root)".
11. Haz clic en "Save".
12. ¡Listo! En 1 minuto GitHub te dará tu enlace web:
    👉 https://tu-usuario.github.io/xv-stefani/

MÉTODO 2: CON GIT POR TERMINAL:
  git init
  git add .
  git commit -m "Invitación de XV Años Stefani Michel"
  git branch -M main
  git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
  git push -u origin main
